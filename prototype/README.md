# 竹寶 Demo（純前端 HTML）

不用安裝任何東西，雙擊 `index.html` 就能在瀏覽器開啟。所有頁面都能用上方導覽列切換。手機寬度下，導覽列會變成「選單」按鈕。

| 檔案 | 分頁 | 內容 |
| --- | --- | --- |
| `setup.html` | 初次設定 | 輸入寶寶出生日期、戶籍區與幾個關鍵問題 |
| `index.html` | 主頁 | 寶寶年紀、這個年紀要注意的事（飲食、疫苗、健檢、發展、安全）、個人化提醒 |
| `diary.html` | 寶寶日記 | 一鍵記錄喝奶、尿布（含便便顏色）、睡眠、體溫，異常即時提醒，7 天趨勢 |
| `benefits.html` | 補助及其他福利 | 依年齡排列的補助與福利，綠／黃／灰等狀態，黃色項目可直接回答問題 |
| `childcare.html` | 托育 | 托嬰中心、公共托嬰篩選 |
| `activities.html` | 親子活動 | 新竹市與其他縣市的活動、親子空間與優惠，可依地區、時間、年齡篩選 |
| `ask.html` | AI 問答 | 6 組示範問答，回答依寶寶資料個人化並附官方來源 |
| `help.html` | 協助 | 緊急專線、各類窗口、常見問題、使用說明與資料隱私 |

示範情境：寶寶 2026/9/10 出生、新竹市北區、第 1 胎、自己帶，今天是 2026/11/14。

`zhubao-runtime.js` 是頁面共用的小型渲染程式，負責把資料填進畫面與處理點擊，不需要網路連線（字型除外）。
