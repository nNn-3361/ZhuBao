# 竹寶 Demo（純前端 HTML）

不用安裝任何東西，雙擊 `index.html` 就能在瀏覽器開啟。

版面：手機優先。底部是文字分頁列：主頁、補助、托育、活動、問竹寶。右上角是選單鍵（三條線，旁邊顯示未讀通知數），通知、寶寶資料、協助、新竹通帳號與同步、通知設定都在裡面。往下捲時，頁面標題會縮到上方列中間；再點一次目前的分頁會回到最上面。電腦上打開任何一頁，會自動進入 `phone.html` 手機展示模式：左邊是手機外框裡的 App，右邊是展示控制（送出推播通知、切換頁面、重新播放載入畫面、從填寫寶寶資料開始）。想看原本的電腦版網頁，點右邊最下面的「改看電腦版網頁」，或在網址後面加 `?web=1`。

系統功能都用畫面模擬，不連任何伺服器：推播橫幅（點一下打開對應頁面、往上滑收起）、通知（未讀數字、全部標為已讀）、通知設定開關、新竹通帳號已連結、同步寶寶資料。

| 檔案 | 分頁 | 內容 |

示範情境：新竹市北區，兩個寶寶檔案：哥哥 2024/2/20 出生（藍）、妹妹 2026/9/10 出生（綠），日期用裝置今天的日期計算。第一次打開會預先放幾個已關注的補助、活動和自己的事件；手機展示頁右側「重設示範資料」可以回到這個狀態。

## 多寶寶與關注

- 切換寶寶：右上角選單裡的「寶寶檔案」，點一個就切換；補助頁和主頁跟著目前選的寶寶。
- 關注：補助卡片（算得出「可開始申請」或「截止」日期的項目）與期間活動卡片點開後有「關注」。補助跟著目前的寶寶；活動關注時選是幫哪個孩子或全家。關注的清單全家共用，存在 `localStorage`。
- 補助日期依每個寶寶的生日推算，只用補助頁已寫明、有官方來源的時間點；「可開始申請」已經過了就不列。
- 通知只通知已關注的項目，日期前 7 天和前 1 天各一次。
- 共用程式：`zhubao-family.js`（寶寶檔案、關注、日期推算、提醒），`zhubao-cal.js`（主頁行事曆）。

每一頁右下角都有浮動的竹寶小助手（AI 問答頁和初次設定頁除外）。點一下會跳出小對話窗，按住標題列可以拖曳（滑鼠、觸控都可以，也能用方向鍵），對話窗會一直留在畫面內。小助手知道你在哪一頁，會先建議和這頁有關的問題；它和 AI 問答頁共用同一份示範回答與歷史紀錄。歷史紀錄只存在這台裝置的瀏覽器裡。

`zhubao-app.js`／`zhubao-app.css` 是 App 外殼（分頁列、通知、更多、推播、手機展示模式切換），每一頁都在 `<head>` 載入。`phone.html` 是電腦上的手機展示頁。`zhubao-news.js` 是主頁的最新消息輪播。`zhubao-ai.js` 放示範問答資料、歷史紀錄與浮動小助手。`zhubao-runtime.js` 是頁面共用的小型渲染程式，負責把資料填進畫面與處理點擊，不需要網路連線（字型除外）。

## 設計規則（依 Appllama App Design Skill 逐頁審查）

- 顏色：一個主色（竹綠 #2E5E4E）＋一組暖灰。分類標籤（疫苗、飲食、喝奶、尿布…）一律用暖灰，不另外配色；只有狀態才用顏色：綠＝可能適用／目前，灰＝可能不適用，紅＝緊急。
- 圓角只用 4、12、16、20、999 五種。
- 可以點的東西至少 44×44；小連結用透明留白擴大可點範圍。
- 按下回饋：小按鈕縮到 0.97，大區塊只淡淡變暗；動畫 300 毫秒內、不回彈；分頁切換不加動畫；尊重「減少動態效果」。
- 短暫的輸入或選擇用從下方滑上來的面板（選單、消息全文），點背景、往下拉或按返回鍵都能關。
- 同一個目的只用一種說法（例如一律「問竹寶」「修改寶寶資料」「看官方說明」）。
- 品牌只有淺色（骨白＋綠），刻意不做深色模式。

## 用字規則

- 不用過度肯定的字：補助只說「可能適用／可能不適用」，不寫「符合」「自動入帳」；點開列出「還要確認的資料」。
- 不放健康判讀內容（寶寶日記已移除，主頁與問竹寶不放疫苗、飲食、便便等健康內容）。
- 活動只列可驗證的基本資訊並附主辦單位活動頁連結。
