# 竹寶 Demo（純前端 HTML）

不用安裝任何東西，雙擊 `index.html` 就能在瀏覽器開啟。

版面：手機優先。手機上方是精簡的標題列（右邊有「通知」），底部是文字分頁列：主頁、日記、補助、問竹寶、更多（托育、親子活動、協助、寶寶資料、新竹通帳號與同步、通知設定都收在「更多」）。往下捲時，頁面標題會縮到上方列中間；再點一次目前的分頁會回到最上面。電腦上打開任何一頁，會自動進入 `phone.html` 手機展示模式：左邊是手機外框裡的 App，右邊是展示控制（送出推播通知、切換頁面、重新播放載入畫面、從填寫寶寶資料開始）。想看原本的電腦版網頁，點右邊最下面的「改看電腦版網頁」，或在網址後面加 `?web=1`。

系統功能都用畫面模擬，不連任何伺服器：推播橫幅（點一下打開對應頁面、往上滑收起）、通知中心（未讀數字、全部標為已讀）、通知設定開關、新竹通帳號已連結、同步寶寶日記。

| 檔案 | 分頁 | 內容 |
| --- | --- | --- |
| `setup.html` | 初次設定 | 輸入寶寶出生日期、戶籍區與幾個關鍵問題 |
| `index.html` | 主頁 | 寶寶年紀、這個年紀要注意的事（飲食、疫苗、健檢、發展、安全）、最新消息（新竹市政府與疾管署公告，左右滑動、每 6 秒換一張，點開放大看全文） |
| `diary.html` | 寶寶日記 | 六個常駐大格子（餵奶、尿布、睡覺、體溫、身高體重、筆記），每格顯示距離上次多久。點任何一格都直接打開一個自己打字的框，不跳出任何選項；可用「＋新增快捷選項」存自己的常用內容（存在這台裝置），點一下填入、長按刪除。時間是無框文字，點了打開時、分兩欄的選擇器；睡覺有睡著與醒來（可選「還在睡」）。儲存旁有可收合的小提醒＋官方連結。從文字判斷便便顏色、體溫、睡姿異常。點日期文字可用日曆切到前 6 天 |
| `benefits.html` | 補助及其他福利 | 依年齡排列的補助與福利，綠／黃／灰等狀態，點開看 AI 說明（補助什麼／重要資訊） |
| `childcare.html` | 托育 | 托嬰中心、公共托嬰篩選 |
| `activities.html` | 親子活動 | 新竹市與其他縣市的活動、親子空間與優惠，可依地區、時間、年齡篩選 |
| `ask.html` | AI 問答 | 完整版問答。左邊是最近 5 筆歷史問答（手機版收在上方），輸入框上方有 3 題示範題，點一下就填入；回答依寶寶資料個人化並附官方來源 |
| `help.html` | 協助 | 緊急專線、各類窗口、常見問題、使用說明與資料隱私 |

示範情境：寶寶 2026/9/10 出生、新竹市北區、第 1 胎、自己帶，今天是 2026/11/14。

每一頁右下角都有浮動的竹寶小助手（AI 問答頁和初次設定頁除外）。點一下會跳出小對話窗，按住標題列可以拖曳（滑鼠、觸控都可以，也能用方向鍵），對話窗會一直留在畫面內。小助手知道你在哪一頁，會先建議和這頁有關的問題；它和 AI 問答頁共用同一份示範回答與歷史紀錄。歷史紀錄只存在這台裝置的瀏覽器裡。

`zhubao-app.js`／`zhubao-app.css` 是 App 外殼（分頁列、通知、更多、推播、手機展示模式切換），每一頁都在 `<head>` 載入。`phone.html` 是電腦上的手機展示頁。`zhubao-news.js` 是主頁的最新消息輪播。`zhubao-ai.js` 放示範問答資料、歷史紀錄與浮動小助手。`zhubao-runtime.js` 是頁面共用的小型渲染程式，負責把資料填進畫面與處理點擊，不需要網路連線（字型除外）。

## 設計規則（依 Appllama App Design Skill 逐頁審查）

- 顏色：一個主色（竹綠 #2E5E4E）＋一組暖灰。分類標籤（疫苗、飲食、喝奶、尿布…）一律用暖灰，不另外配色；只有狀態才用顏色：綠＝符合／目前，黃＝需確認，紅＝緊急或異常。
- 圓角只用 4、12、16、20、999 五種。
- 可以點的東西至少 44×44；小連結用透明留白擴大可點範圍。
- 按下回饋：小按鈕縮到 0.97，大區塊只淡淡變暗；動畫 300 毫秒內、不回彈；分頁切換不加動畫；尊重「減少動態效果」。
- 短暫的輸入或選擇用從下方滑上來的面板（更多、通知、消息全文、寶寶日記的打字框），點背景、往下拉或按返回鍵都能關。
- 同一個目的只用一種說法（例如一律「問竹寶」「修改寶寶資料」「看官方說明」）。
- 品牌只有淺色（骨白＋綠），刻意不做深色模式。
