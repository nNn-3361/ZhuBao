# 竹寶 ZhuBao：AI 育兒管家

> 115 年新竹政策黑客松 **佳作** 作品展示（團隊 N.A.W.Y）

竹寶是為新竹市家長設計的 AI 育兒管家。輸入寶寶的生日（或預產期）和戶籍，就能依孩子的年紀整理出可能用得到的資源：

- **補助生命線**：用一根竹子依年齡分段，列出各階段可能適用的補助與福利，附官方來源。
- **托育**：查詢新竹市托嬰中心與居家托育服務中心。
- **親子活動**：全台對孕婦、兒童有優惠的場館與新竹市親子館活動。
- **問竹寶**：AI 問答，依寶寶資料回答補助、托育相關問題。
- **行事曆與提醒**：關注的補助與活動，在日期前提醒。
